# Delta Run privacy policy

Last updated: 13 October 2026

Delta Run is a game that runs entirely on your device.

- It does not collect, store or send any personal data.
- It has no accounts, no ads, no analytics and no tracking.
- It does not use the internet.
- It does not ask for access to your contacts, photos, location, camera
  or microphone.

If a game controller is connected, the game reads its buttons only while
you play. On iPhone, the game can make the phone vibrate briefly when your
plane crashes.

If this policy ever changes, the new version will be posted on this page
with a new date.

Questions: open an issue at
<https://github.com/akaco/river-raid-rust/issues>.
